# 040 Google-Maps Layout — Tasks

Each task is atomic and maps to exactly one acceptance criterion: it adds one
thing and removes what replaces it. There must be exactly one form and one
controls surface at any size.

- [ ] T1 (AC-1, AC-3): Make the map full-bleed and the layout responsive in `frontend/src/App.svelte`. `<main>` holds the map (`<div id="map">`, full-viewport) as the primary surface. **Remove** the fixed two-column `grid-template-columns: minmax(280px, 360px) 1fr` and the always-on `<aside>`: the sidebar is rendered **only** at desktop width (≥768px), and the bottom drawer only below it. On mobile the map fills the viewport with no sidebar column. Do not render the sidebar and the drawer at the same size. This task is the *shell* only — the controls content comes in T3.
- [ ] T2 (AC-2): Add `frontend/src/lib/components/TopSearchCard.svelte` and render it once over the top of the map: origin row (blue my-location dot + "My location"), a drag-handle divider, destination row (red pin + address), and `⋯`/`↑↓` action icons — each row wired to the existing `SearchInput`, keeping the ⌖ pick buttons and the search placeholder text. **Remove** any old Start/End `<form>` from the sidebar/aside so this is the ONLY form (no duplicate).
- [ ] T3 (AC-4): Add `frontend/src/lib/components/BottomDrawer.svelte` (collapsed by default, grab-handle pill, expands in place) and put the controls content in it **and** in the desktop sidebar: the route summary (duration · distance · arrival · terrain/comfort), Preferences, Saved routes, and the action buttons. No transport-mode selector (walking only). `loadSaved`/`loadPrefs` still run on mount.
- [ ] T4 (AC-5): On the first geolocation fix, centre the map and pre-fill the origin field with the current position (reverse-geocode it); a manual origin overrides it.
- [ ] T5 (AC-6): Add `frontend/src/lib/map/material.ts` with inlined Material Symbols SVG paths (24×24 viewBox, `fill="currentColor"`) for `my_location`, `place`, `swap_vert`, `more_horiz`, `tune`, `share`, `close`, `directions_walk`, `search`, and use them in the top card, the drawer/sidebar and `frontend/src/lib/map/icons.ts` (replacing the Bootstrap glyph and the A/B pins).
- [ ] T6 (AC-7): Run `make e2e`, `npm run check`, `npm test` and fix any regression; confirm the e2e hooks (`.comfort-band`, `.comfort-legend`, `button.walk-start`, the search input) still resolve.
